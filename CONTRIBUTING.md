# Contributing

Thanks for taking a look. A few ground rules:

- Run the tests and `clang-format` before opening a pull request.
- New parsers need tests with broken input, not only valid files.
- Say where your information comes from (public docs, public source, your own
  build). Guessed offsets, ordinals or ABIs will not be merged.
- Do not submit SDK headers or libraries, console dumps, keys, game files or
  anything under NDA. Not in code, not in issues.
- New dependencies should come with a reason.

For bigger changes, open an issue first so we can talk about it.
